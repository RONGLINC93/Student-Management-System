# 智能分班系统

一个基于纯 Node.js（零依赖）的智能分班系统，提供学生信息管理、班级/年级管理与「随机排位 + 均衡编班」动画效果。分班流程贴近课堂场景：学生卡片正面朝上随机换位排定顺序，再依次飞入各班，全程无扑克式翻背效果。

## 功能特性

### 学生列表（index.html）
- 学生信息统计：总人数、男生/女生数、平均总分
- 按姓名/学号/特长搜索，按年级、分班状态筛选
- 分页浏览（10/20/50/100 条每页，设置自动持久化）
- 添加/编辑/删除学生，批量导入示例数据
- **下载示例表格**：导出 CSV 模板（UTF-8 BOM，Excel 打开不乱码）
- **导入表格数据**：按表头名解析 CSV 文件批量导入，跳过姓名为空的行并提示行号

### 班级管理（classes.html）
- 班级的新增、编辑、删除（删除后学生自动退回学生池）
- 班级卡片拖拽排序，顺序持久化（搜索/筛选时自动禁用排序）

### 年级管理（grades.html）
- 年级的新增、重命名、删除，拖拽排序
- 重命名/删除年级会同步更新学生与班级数据
- 年级排序影响智能分班页的年级下拉顺序

### 智能分班（allocate.html）
- 随机排位动画：学生卡片正面朝上、网格平铺，连续多轮随机换位（Fisher-Yates），卡片借助位移过渡平滑「打乱」，最终顺序即排位结果
- 分班策略可选：S型蛇形（按总分均衡）、综合均衡（成绩+性别+特长）、随机分班
- 依次分班动画：每张卡片先放大展示到舞台中央（1.1–2.5 倍可调）并标注目标班级，再旋转飞入对应班级
- 动画速度 1–5 档可调；策略、速度、展示大小均自动持久化
- 分班前必须选择年级；随机排位/分班过程中顶部按钮禁用，悬浮按钮自动隐藏并在两种模式间切换
- 分班结果一键提交持久化，展示各班级人数与总分均衡统计（最高/最低/差值）
- 投屏结果大屏（`result.html`）：分班过程中实时推送快照（内存态），学生列表页 / 分班页可打开大屏看板同步观看

### 分班结果大屏（result.html）
- 独立投屏页：深色大屏布局，适合第二块显示器或投影展示
- 自动轮询（0.8s）聚合接口 `/api/board`（持久班级 + 学生池 + 实时快照）
- 大屏始终只展示一个年级（无「全部年级」汇总视图）：直播分班中只播直播所在年级；空闲并开启「跟播」时跟随分班页广播的当前年级，年级未确定时进入「等待同步」空态
- 顶部概览：班级总数 / 已分班学生 / 学生池剩余 / 总容量（均按当前展示年级统计，「学生池剩余」仅含该年级未分班学生）
- 各班卡片大盘点：当前人数、容量进度条、男女人数、平均总分，点击卡片展开完整花名册
- 分班演示过程中「LIVE」状态点亮，班级人数与学生池剩余随入班动画实时变化
- 分班页点击「随机排位」即同步大屏提示：控制条中部胶囊与「LIVE」角标分别呈现「正在随机排位 → 排位完成 · 待开始分班」，观众无需盯操作页也能跟随流程
- 每个学生都完整播放入场动画（顶部起飞 → 展示台 → 飞入座位），绝不"闪现"入座；直播结束后未播完的队列会逐个播完再点亮座位，队列积压时自动压缩各段时长以贴近分班页节奏

## 快速开始

```bash
# 方式一
node server.js

# 方式二
npm start

# 方式三（Windows）
双击 运行.bat
```

浏览器访问 <http://localhost:3000>

> 修改 `server.js` 后需重启服务；修改 `public/` 下的前端文件刷新页面即可生效（静态资源已禁用缓存）。

## API 一览

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/students` | 获取未分班学生 |
| GET | `/api/all-students` | 获取全部学生（含已分班，标记分班状态） |
| POST | `/api/students` | 新增学生 |
| PUT/DELETE | `/api/students/:id` | 更新/删除学生 |
| POST | `/api/students/batch` | 批量导入学生（数组） |
| DELETE | `/api/students` | 清空学生 |
| GET/POST | `/api/classes` | 获取/新增班级 |
| PUT | `/api/classes/order` | 班级拖拽排序持久化 |
| PUT/DELETE | `/api/classes/:id` | 更新班级/删除班级（学生退回池） |
| POST | `/api/classes/:id/remove/:stuId` | 单个学生退回学生池 |
| GET/POST | `/api/grades` | 获取/新增年级 |
| PUT | `/api/grades/order` | 年级拖拽排序持久化 |
| PUT/DELETE | `/api/grades/:name` | 重命名/删除年级 |
| POST | `/api/allocate` | 提交分班结果 |
| GET/PUT | `/api/filters` | 前端筛选与设置持久化 |
| POST/DELETE | `/api/live` | 推送/清除实时分班快照（内存态，供大屏轮询） |
| GET | `/api/board` | 大屏聚合数据：持久班级 + 学生池 + 年级 + 实时快照 |

## CSV 导入格式

点击「更多 → 下载示例表格」获取模板，表头如下（列顺序无关，`姓名` 必填）：

```csv
学号,年级,姓名,性别,语文,数学,英语,理综,特长
2024001,高一,张伟,男,88,92,85,90,篮球
```

- 性别非「女」时默认按「男」处理
- 成绩列为空或非数字时按 0 处理
- 姓名为空的行会被跳过，导入完成后提示跳过的行号

## 使用注意事项

- 智能分班前必须先选择年级
- 随机排位/分班进行中时，顶部操作按钮禁用、悬浮按钮自动隐藏；若中途切换年级会先自动重置当前进度
- 学生人数不能少于班级数
- 危险操作（删除、清空等）均需弹窗二次确认
- 搜索或筛选生效时，班级/年级卡片拖拽排序自动禁用，以保证全局顺序正确
