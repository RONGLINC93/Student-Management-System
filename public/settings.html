学校信息
学校名称、校徽、学年与联系信息 —— 展示于各页顶栏 / 工作台品牌 / 浏览器标题 / 分班结果大屏

建议使用正方形 PNG（透明底更佳），上传后自动等比缩小到 300px 内，将替换各页面顶部、后台工作台与大屏的默认图标。

填写后，各功能页顶部大字、工作台品牌与浏览器标签会一并更新；留空保持默认“学生管理系统”。

如「2026 年秋季」，以胶囊形式显示在分班结果大屏的副标题处。

填写的网址会以「官网」入口出现在各功能页顶栏与后台工作台右上角（新窗口打开），并同步显示在分班结果大屏页面底部；不填或删除即隐藏入口。保存时自动补全为 http/https。

校训 / 地址 / 电话会显示在分班结果大屏的页面底部一行，便于投屏展示时对外联系。

分班规则 · 综合均衡强度
仅影响分班页「综合均衡（成绩+性别+特长）」策略下的排序倾向

数值越大，分班时越优先让每个班的男女生比例接近，建议 1～2。

数值越大，越倾向于把“有特长”的学生打散到不同班级，建议 1～2。

考试科目设置
定义学生档案成绩、考试成绩录入与各页统计使用的科目（含满分）。改动后会自动同步学生档案、成绩管理、数据总览与分班参考成绩。

提示：删除科目后，历史成绩与考试记录仍会保留在数据文件中，只是不再显示与统计；重新添加同名科目即可恢复展示。 默认科目建议保留「语文 / 数学 / 英语 / 理综」以便与原有分班参考成绩衔接。

数据备份与维护
导出 / 导入数据备份，导入示例年级 / 班级 / 宿舍 / 学生数据，集中管理「清空学生档案」「清空全部班级」等高危维护操作

导出得到一个 JSON 备份文件；换电脑 / 误删后可在“导入备份文件”中选择该文件一键恢复。 导入将 覆盖 当前全部数据，请谨慎操作。

备份时间 保留 份自动备份

开启后，服务每天到达设定时间时自动把全量数据备份到服务器 data/backups 目录； 服务停机跨过备份时刻时，启动后会自动补备份一份。仅自动备份按保留份数清理，手动备份永久保留。

备份文件类型生成时间大小操作

一键写入体验用的示例数据，按 年级 → 班级 → 宿舍 → 学生 顺序执行：3 个年级（高一 / 高二 / 高三）、 6 个班级（每个年级 2 个班，容量 50）、6 间宿舍（1 号楼男生 101～103、2 号楼女生 101～103，4 人间）、 12 名学生（覆盖三个年级，含各科成绩与特长）。

全部为追加写入：已存在的年级 / 班级 / 房间会自动跳过，不会覆盖或删除已有数据；示例成绩按当前「考试科目设置」的科目生成； 示例学生导入后为未分班、未住宿状态，可自行体验智能分班、宿舍分配与成绩统计。学生重复导入会产生同学号的多条档案，可用下方「清空学生档案」一次性移除。

两者均为不可恢复的高危操作：清空学生档案 将删除学生、各班花名册及宿舍 / 操行记录，但保留班级结构；清空全部班级 将删除班级本身，已分班学生退回未分班，学生档案保留。操作前建议先「导出数据备份」。

账号与安全

账号列表加载中…

「管理员」可操作全部功能与数据；「查看模式」仅可查看各页与大屏，系统设置与所有修改 / 删除操作将被拒绝；职位含「教务」或「宿管」的教师可在管理员入口登录，分别获得「教务」「宿管」角色，二者可管理的模块可在「职位权限」中按需调整（默认：教务可管学生、班级、年级、成绩、考勤操行、公告，请假审批由班主任在教师端完成、宿舍归宿管管理；宿管仅宿舍；教务与宿管权限相互独立，不合并授权）。系统始终需保留至少一个管理员账号。学生账号随学生首次登录「学生入口」自动创建（账号、初始密码均为学号，首次登录强制修改密码），教师账号随教师首次登录「教师入口」自动创建（账号为工号、初始密码为身份证号后 6 位，首次登录强制修改密码），此处均可为其重设密码，但角色不可修改。

上方总览表列出全部角色的权限：管理员、查看模式为固定权限，教师端与学生端不走管理后台，仅「教务 / 宿管」可在此配置。勾选的模块对该职位开放读写（含增删改、审批等写操作），未勾选的模块仅可查看；教师管理、智能分班、大屏直播、备份 / 审计、服务器管理、系统设置始终仅限管理员，不开放配置。默认配置：教务可管理学生、班级、年级、成绩、考勤操行、公告（请假、宿舍默认不开放——请假审批由班主任在教师端完成，宿舍归宿管管理）；宿管仅可管理宿舍。职务同时含「教务」与「宿管」的教师按教务身份登录，仅按教务职位权限授权（不并入宿管模块）。权限变更保存后立即生效，新登录或刷新后的会话将按新权限展示操作按钮，服务端始终以本设置硬拦截未授权的写请求。
